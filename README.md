# 🏙️ LINK CITY 2050 (링크 시티 2050)

> **크루스칼 알고리즘(MST)을 활용한 수학·과학 융합형 2050 친환경 스마트시티 건설 전략 게임**  
> 중·고등학생을 위한 직관적이고 몰입감 넘치는 2.5D 솔라펑크 교육용 웹 애플리케이션

---

## 🌟 프로젝트 개요

**LINK CITY 2050**은 그래프 이론의 핵심인 **최소 신장 트리(Minimum Spanning Tree, MST)**와 **크루스칼 알고리즘(Kruskal's Algorithm)**의 수학적 원리를 재미있는 게임 메커니즘으로 체득할 수 있도록 설계된 교육용 웹 게임입니다.

플레이어는 2050년 미래 생태 스마트시티의 인프라 수석 엔지니어가 되어, 제한시간 내에 최소한의 건설비로 도시의 모든 친환경 첨단 시설들을 순환선(사이클) 없이 하나로 연결해야 합니다.

---

## 🎮 게임 모드

### 1. 자유 건설 모드 (1~4인용)
- **1인용 (스마트시티 챌린지)**: 크루스칼 알고리즘과 기록을 겨루며 최적 비용을 달성하는 싱글 타임어택 모드.
- **2인용 (네트워크 듀얼)**: 동일한 지도와 제한시간 조건에서 펼쳐지는 1:1 진검승부 턴제 핫시트 대결.
- **3인용 (스마트시티 리그)**: 3명의 전략가가 최적의 인프라 연결망을 탐구하는 삼국지 리그전.
- **4인용 (LINK CITY 챔피언십)**: 4인이 참가하는 공식 마스터 토너먼트 종합 랭킹전.

> 🔒 **공정 경쟁 비밀 보장**: 2~4인 모드에서는 플레이어 교대 시 이전 도전자의 선택 도로와 결과를 완전히 숨겨 독립적인 전략 수립을 보장합니다.

### 2. 크루스칼 알고리즘 인터랙티브 학습 모드
- 전체 도로망 후보를 가중치(비용) 오름차순으로 탐욕적(Greedy)으로 검토.
- 미검토 최저 비용 도로를 선택하고, **사이클(순환선) 형성 여부를 스스로 판단**하는 단계별 퀴즈.
- 정확히 $n - 1$개의 도로를 채택하면 최소 신장 트리(MST) 완성!
- 게임 종료 후 나의 연결망과 크루스칼 최적해를 단계별로 돌려볼 수 있는 **인터랙티브 재생기(Replayer)** 제공.

## 🔬 미래 도시 과학 학습 콘텐츠

도시 지도에 배치된 8대 첨단 미래 시설의 과학적 원리를 학습할 수 있습니다.
- ☀️ **태양광 발전소**: 빛에너지와 전기에너지 변환 (광전효과 & ESS)
- 🏥 **스마트 병원**: 의료 데이터와 원격 진료 (IoT 생체 센서 & 실시간 전송)
- 🧠 **AI 연구소**: 인공지능과 데이터 분석 (딥러닝 알고리즘 & 빅데이터 예측)
- 🚗 **자율주행 교통 허브**: 센서와 자동 제어 (라이다 LiDAR & V2X 무선 통신)
- 🏡 **친환경 주거단지**: 에너지 절약 건축 (패시브 하우스 & 제로에너지 ZEB)
- 🖥️ **데이터 센터**: 정보 처리와 통신망 (양자 암호 통신 & 친환경 수랭식 쿨링)
- 🌿 **스마트 농업 돔**: 생육 환경 자동 제어 (LED 광합성 파장 & 스마트 팜 IoT)
- ⚡ **수소 에너지 센터**: 수소 저장 및 연료전지 (수전해 청정 수소 & Fuel Cell)
- 💡 **보너스 과학 퀴즈**: 게임 종료 후 점수에 영향을 주지 않는 4지선다형 과학 상식 퀴즈 1문항 제공.

## 🗺️ 난이도별 지도 규격

| 난이도 | 도시명 | 시설 수 ($n$) | 도로 후보 | 목표 도로 수 ($n-1$) | 최소 비용 |
|:---:|:---|:---:|:---:|:---:|:---:|
| **쉬움** | 네오 송도 스마트 아일랜드 | 6개 | 9개 | 5개 | **13억 원** |
| **보통** | 판교 테크노 밸리 2050 | 8개 | 13개 | 7개 | **18억 원** |
| **어려움** | 메가 에코폴리스 센트럴 2050 | 10개 | 17개 | 9개 | **23억 원** |

*동일한 최소 가중치 합을 갖는 **복수 최소 신장 트리(Multiple MSTs)** 조합도 수학적으로 완벽하게 정답으로 인정합니다.*

## 🛠️ 기술 스택 및 구조

- **Core Engine**: TypeScript, Union-Find (Disjoint Set Union), Kruskal Algorithm
- **Graphics & UI**: Vanilla SVG, CSS Modern Design System (Glassmorphism, 2.5D Isometric Solarpunk)
- **Framework**: React 18, Vite
- **Testing**: Node.js Test Runner, Vitest (총 66개 단위 및 통합 테스트 100% 통과)
- **Deployment**: GitHub Pages (정적 호스팅, 서버리스)

### 폴더 구조
```text
LINK-CITY-2050/
├── dist/                     # GitHub Pages 정적 배포 번들 (index.html)

│   ├── buildStatic.mjs       # 제로 의존성 정적 단일 파일 배포 빌더
│   ├── fullIntegrationTest.mjs # 15대 항목 종합 통합 테스트 러너
```

## 🚀 실행 및 테스트 방법

### 1. 로컬 개발 서버 실행
```bash
# 개발 서버 구동 (별도 무거운 설치 없이 즉시 실행 가능)
npm run dev

# 브라우저에서 접속
http://localhost:3000
```

### 2. 테스트 스위트 실행
```bash
# 1) 코어 엔진 34개 단위 테스트
npm test

# 2) 15대 항목 종합 통합 테스트 (32개 전수 검사)
node scripts/fullIntegrationTest.mjs
```

### 3. 배포용 번들 빌드
```bash
# GitHub Pages용 정적 번들 빌드 (dist/index.html 생성)
npm run build
```

## 🌐 GitHub Pages 배포 방법

1. 저장소의 `Settings` $\to$ `Pages` 메뉴로 이동합니다.
2. **Build and deployment** 항목의 **Source**를 `Deploy from a branch`로 설정합니다.
3. **Branch**를 `main` 브랜치의 `/ (root)` 폴더 (또는 `/docs`)로 지정하고 **Save**를 클릭합니다.
4. 배포 완료 후 제공되는 URL(예: `https://<username>.github.io/link-city-2050/`)로 접속하여 게임을 플레이할 수 있습니다.
